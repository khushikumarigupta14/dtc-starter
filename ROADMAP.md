# Roadmap

- Phase 0 — Foundation: PostgreSQL, Medusa/Admin, Next.js, India/INR, COD, local uploads, documentation and standards.
- Phase 1 — Catalog: homepage, gallery/detail, images, categories/collections, price, stock, sold UI.
- Phase 2 — Cart and COD checkout: cart, contact/address, shipping, COD, order, confirmation, Admin verification.
- Phase 3 — Artist content: About, story, process/studio, contact.
- Phase 4 — Custom artwork requests: form, optional reference, source artwork, validation, Admin handling and statuses.
- Phase 5 — Customer account: authentication, profile, order history/detail.
- Phase 6 — Quality: SEO, accessibility, responsive polish, states, tests, performance, security review.

Future and uncommitted: production storage, online payments, transactional email, courier integration, reviews, wishlists, analytics, and advanced quote workflow.
